DuckOn Backend

K-POP 팬 커뮤니티 플랫폼 백엔드 서버. 실시간 채팅, 아티스트 관리, 팬 커뮤니티 기능을 제공합니다.

Spring Boot 3.5.3 Java 21 MySQL 8 MongoDB Redis 7 WebSocket / STOMP
⚡

빌드 & 실행 명령어

# 빌드
./gradlew build
./gradlew clean build

# 실행
./gradlew bootRun

# 전체 테스트
./gradlew test

# 단일 테스트 클래스 또는 메서드 실행
./gradlew test --tests "com.a404.duckonback.SomeTest"
./gradlew test --tests "com.a404.duckonback.SomeTest.methodName"

인증 흐름

1

JWT 발급

액세스 토큰 15분 은 응답 바디로 반환, 리프레시 토큰 2주 는 HttpOnly 쿠키로 전달.

2

토큰 갱신

POST /api/auth/refresh 로 리프레시 토큰을 검증하여 새 액세스 토큰을 발급합니다.

3

로그아웃

토큰을 Redis 블랙리스트 common/security/token/ 에 추가한 뒤 쿠키를 삭제합니다.

4

OAuth2 소셜 로그인

각 프로바이더가 /login/oauth2/code/{google|kakao|naver} 로 리다이렉트. 성공 시 ${BASE_URL}/oauth2/success, 실패 시 /oauth2/failure 로 이동.

📡

응답 & 에러 컨벤션

모든 엔드포인트는 ApiResponseDTO 형식으로 응답합니다.

{
  "status": 200,
  "message": "요청이 성공적으로 처리되었습니다.",
  "data": { ... }
}

❌ 에러 처리

  • CustomException(ErrorCode.XXX) 를 던지면
  • GlobalExceptionHandler 가 자동 변환
  • Spring 표준 예외도 통합 처리

➕ 새 코드 추가

  • common/response/ErrorCode 에 추가
  • common/response/SuccessCode 에 추가
  • 열거형에 HTTP 상태 + 메시지 정의
🗄

엔티티 컨벤션

📅 감사 필드

  • createdAt, updatedAt 자동 관리
  • BaseLastModifiedAuditEntity 상속

🗑 소프트 삭제

  • boolean deleted + deletedAt
  • 모든 쿼리에 deleted = false 필터
  • 데이터 복구 가능

🔢 열거형 저장

  • @Enumerated(EnumType.STRING)
  • DB에 문자열로 저장 (리팩터링 안전)

⚡ N+1 방지

  • @Query JPQL 활용
  • left join fetch 적극 사용
  • 연관 엔티티 한 번에 로드
